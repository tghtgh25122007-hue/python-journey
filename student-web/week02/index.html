08

Phòng Lab Lỗi phổ biến & Cách xử lý (Tuần 02)

Thử chạy từng lỗi hay gặp nhất khi học Biến, Kiểu dữ liệu & input(), xem cách sửa đúng hoặc mở thẳng sang Live IDE để tự sửa

ValueError

1. Ép kiểu chữ sang số: int("ba")

Nguyên nhân: int() chỉ hiểu chuỗi chứa chữ số nguyên ("42"). Gặp chữ "ba" hoặc số thập phân "3.14" sẽ văng ValueError.

Cách xử lý: Kiểm tra text.isdigit() trước khi gọi int(); nếu là số thập phân thì dùng float().

Bấm nút bên trên để so sánh bản LỖI và bản ĐÃ SỬA.
TypeError

2. Cộng chuỗi với số: "18" + 1

Nguyên nhân: Python không tự đổi str sang int khi dùng dấu +. Cộng "Tuổi: " + 20 hoặc "18" + 1 đều báo TypeError.

Cách xử lý: Ép sang số int("18") + 1 khi cần tính toán, hoặc dùng f-string (f"Tuổi: {20}") khi cần in.

Bấm nút bên trên để so sánh bản LỖI và bản ĐÃ SỬA.
Logic Bug

3. Quên ép kiểu input(): "12" + "3" == "123"

Nguyên nhân: input() luôn trả về str. Nếu cộng trực tiếp 2 kết quả input(), chương trình không báo lỗi nhưng lại nối chuỗi thành "123" thay vì 15.

Cách xử lý: Luôn bọc int(input(...)) hoặc float(input(...)) trước khi tính toán.

Bấm nút bên trên để so sánh bản LỖI và bản ĐÃ SỬA.
ZeroDivisionError

4. Chia cho 0 (Máy tính / BMI / Đổi tiền)

Nguyên nhân: Người dùng nhập số chia, tỷ giá hoặc chiều cao bằng 0 khiến phép / hoặc // làm sập chương trình.

Cách xử lý: Kiểm tra điều kiện if b != 0: (hoặc if chieu_cao > 0:) trước khi thực hiện phép chia.

Bấm nút bên trên để so sánh bản LỖI và bản ĐÃ SỬA.
NameError

5. Sai tên biến / Phân biệt hoa-thường

Nguyên nhân: Khai báo diem_tb nhưng lúc in lại gõ diem_TB hoặc diemtb. Python phân biệt chữ hoa/chữ thường.

Cách xử lý: Thống nhất đặt tên snake_case toàn chữ thường và kiểm tra kỹ tên biến trong dòng báo lỗi Traceback.

Bấm nút bên trên để so sánh bản LỖI và bản ĐÃ SỬA.
Bẫy hay gặp

6. bool("False") là True & int(3.99) là 3

Nguyên nhân: Mọi chuỗi không rỗng (kể cả "False", "0") khi ép bool() đều là True; còn int(3.99) cắt phần thập phân chứ không làm tròn.

Cách xử lý: So sánh trực tiếp text.lower() == "true" cho boolean, và dùng round(3.99) nếu muốn làm tròn.

Bấm nút bên trên để so sánh bản dễ nhầm và bản đúng chuẩn.
